# 🏨 Grand Horizon – Hotel Booking System

A full-stack Hotel Booking System developed using Java, Spring Boot, MySQL, and HTML, CSS, and JavaScript.

## 🌐 Live Website
https://grand-horizon-hotel-booking-system.onrender.com/

## 💻 GitHub Repository
https://github.com/kendreram59/Grand-Horizon-Hotel-Booking-System

## ✨ Key Features
- Customer Registration and Login
- Hotel Room Listing
- Room Management (Add, Update, Delete, View)
- Room Booking Functionality
- Booking Management
- Admin Dashboard
- RESTful Web Services
- MySQL Database Integration
- Responsive User Interface

## 🏗️ Project Architecture

The application follows a layered architecture:

- Controller Layer – Handles HTTP requests.
- Service Layer – Implements business logic.
- Repository Layer – Performs database operations.
- Entity Layer – Manages database entities.

## 🔗 API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/rooms` | Get all rooms |
| POST | `/api/rooms` | Add a room |
| PUT | `/api/rooms/{id}` | Update a room |
| DELETE | `/api/rooms/{id}` | Delete a room |

## 🚀 Run Locally

1. Clone the repository:

   `git clone https://github.com/kendreram59/Grand-Horizon-Hotel-Booking-System.git`

2. Import the project into Eclipse IDE.
3. Configure your MySQL database.
4. Set the required database environment variables.
5. Run the Spring Boot application.
6. Open `http://localhost:8080/` in your browser.

## ☁️ Deployment

- Backend and frontend deployed on Render.
- Docker used for application deployment.
- MySQL cloud database integration.
